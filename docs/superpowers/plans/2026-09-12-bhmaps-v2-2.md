# BhMaps 2.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship BhMaps 2.2: pictures grouped by pack instead of "custom", one My Backgrounds switch on Backgrounds, All maps in the background editor, a platform editor with Opacity and Hue, a stacked map panel, packs ordered by last use, quieter tile menus and chips, the panel's platform files list without seasonal art, New pack, smooth scrolling.

**Architecture:** Nothing on disk changes shape. Core gains four pure pieces (`PackOrder`, `RelativeTime`, `PlatformRecolor`, `PackCreator`) and two settings keys; `MapCatalog.Entry` starts skipping themed nodes. The shell sorts packs once per scan and every list downstream keeps that order. The platform editor is the background editor's twin: a view model that writes processed PNGs into a temp pack-shaped folder and previews through `MapCompositor.Render` with that folder as `packRoot`. Tasks are ordered so the app builds, tests and runs after every commit: order and stamp first (everything else reads the order), then the grouping and strings (every later screen uses the words), then the switch, then the editors, then the panel and menus, then New pack and scrolling, then the release.

**Tech Stack:** .NET 10, WPF, CommunityToolkit.Mvvm 8.4.2, xUnit 2.9.3 (tests\BhMaps.Core.Tests, net10.0-windows), `dotnet format BhMaps.slnx`.

**Spec:** `docs/superpowers/specs/2026-09-12-bhmaps-v2-2-design.md` (binding). Its section numbers are cited as "spec N" below. Review pages: https://claude.ai/code/artifact/8178d1a5-a04f-48a5-887a-3f60d7c9cbe6 and https://claude.ai/code/artifact/db71b24e-cf8b-4309-8a73-ecb617058f83.
